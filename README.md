# 草莓月亮熱氣球

IU 2022 演唱會「The Golden Hour」〈strawberry moon〉熱氣球橋段的粉絲致敬網頁小遊戲（Three.js，手機直接用瀏覽器玩）。

## 玩法
- 左半邊拖曳：移動熱氣球；右半邊拖曳：轉鏡頭
- 🔥 按住升空，👋 靠近發光看台揮手，收集 💗
- 向 8 個看台區揮手後，回到舞台前的降落點落地過關
- ⏸ 暫停；開始畫面或暫停選單可切換畫質（高／標準／低）

## 執行
```bash
python -m http.server 8765
```
然後打開 http://localhost:8765 。

## 音樂
專案不附音樂檔。把自己的音檔改名為 `strawberry-moon.mp3` 放進 `music/`，或在開始畫面選擇音檔。

非官方粉絲作品，與 IU 及 EDAM Entertainment 無關。
